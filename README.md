# 채용 모아보기

문화예술 기관 채용공고를 하루 한 번(아침 8시 전후) 자동으로 모아서 보여주는 사이트입니다.

- **분류**: 정규직 / 계약직·기간제(무기계약직 포함) / 인턴 / 대외활동(서포터즈·자원봉사)
- **NEW 표시**: 최근 3일 안에 새로 잡힌 공고
- **정렬**: 마감 임박 순. 마감된 공고는 아래 '마감된 공고'에 회색으로 모아 둠
- **직무 필터**: 경영지원 · 경영기획 · 전략기획 · 홍보마케팅
- **이메일 알림**: 새 공고가 있는 날에만 발송
- **수집 실패 표시**: 사이트가 바뀌어서 못 가져온 기관은 상단 경고 + '기관 목록'에 ⚠ 표시
- PC/휴대폰 둘 다 볼 수 있고, 비용은 0원 (GitHub 무료 기능)

공고 내용은 복사하지 않고, 제목과 원문 링크만 보여줍니다.

---

## 처음 한 번만 하는 설정 (약 20분)

### 1. 저장소 만들기
1. GitHub에 로그인 → 오른쪽 위 `+` → **New repository**
2. Repository name: `job-board` → **Public** 선택 → **Create repository**
   (GitHub Pages를 무료로 쓰려면 Public이어야 해요. 공고 목록만 공개되고, 이메일·키는 비밀값으로 저장돼서 공개되지 않아요.)
3. 이 폴더의 파일을 전부 올립니다. (Claude에게 저장소 이름을 알려주면 대신 올려줄 수 있어요.)

### 2. 공공데이터포털 API 키 받기 (문체부 산하 공공기관 공고용, 무료)
1. https://www.data.go.kr 회원가입 → 로그인
2. **'공공기관 채용정보 조회서비스'** 검색 (제공기관: 재정경제부) → **활용신청** (개발계정은 자동 승인)
3. 마이페이지 → 데이터활용 → Open API → 활용신청 현황 → 해당 서비스의 **일반 인증키(Decoding)** 를 복사
   (승인 후 실제로 쓸 수 있게 되기까지 1~2시간 걸릴 수 있어요.)

### 3. 네이버 메일 보내기 설정 (알림용)
1. 네이버 메일 → 왼쪽 아래 **환경설정** → **POP3/IMAP 설정** → **IMAP/SMTP 사용: 사용함** → 저장
2. 네이버 2단계 인증을 쓰고 있다면 **네이버 내정보 → 보안설정 → 애플리케이션 비밀번호**에서 새 비밀번호를 만듭니다.
   (2단계 인증을 안 쓰면 평소 네이버 비밀번호를 사용)

### 4. 비밀값 넣기
저장소 → **Settings** → **Secrets and variables** → **Actions** → **New repository secret** 으로 아래 6개를 하나씩 추가합니다.

| Name | 값 |
|---|---|
| `DATA_GO_KR_KEY` | 2번에서 복사한 인증키 |
| `SMTP_HOST` | `smtp.naver.com` |
| `SMTP_PORT` | `465` |
| `SMTP_USER` | 네이버 메일 주소 전체 (예: `myid@naver.com`) |
| `SMTP_PASS` | 3번의 비밀번호 |
| `MAIL_TO` | 알림 받을 메일 주소 |

### 5. 사이트 켜기 (GitHub Pages)
저장소 → **Settings** → **Pages** → Source: **Deploy from a branch** → Branch: `main`, 폴더: `/docs` → **Save**
1~2분 뒤 `https://아이디.github.io/job-board/` 에서 열립니다. 휴대폰에서는 이 주소를 **홈 화면에 추가**해 두면 앱처럼 쓸 수 있어요.

### 6. 첫 수집 실행
저장소 → **Actions** 탭 → (처음이면 활성화 버튼 클릭) → **채용공고 수집** → **Run workflow**
3~5분 뒤 사이트를 새로고침하면 공고가 보여요.
첫 수집 때 잡힌 공고는 'NEW'와 메일 없이 기본 목록으로 들어가고, **다음 날부터 새로 올라온 공고만** NEW 표시와 메일이 와요.

## 사이트에서 분류 고치기 · 기관 추가하기

사이트 오른쪽 위 **⚙(관리 설정)** 에 GitHub 토큰을 한 번 넣으면, 그 기기에서 아래 기능이 켜져요.
- 공고마다 **분류 바꾸기**(드롭다운), **숨기기**
- '기관 목록' → **+ 기관 추가**, 기관 **삭제**
- **지금 수집 실행** 버튼

**토큰 만드는 법**: GitHub → 오른쪽 위 프로필 → Settings → Developer settings → Personal access tokens → **Fine-grained tokens** → Generate new token
- Repository access: **Only select repositories** → `job-board`
- Permissions: **Contents: Read and write**, **Actions: Read and write**
- 만든 토큰(`github_pat_…`)을 복사해서 ⚙ 설정에 붙여넣기

토큰은 그 브라우저에만 저장돼요. PC와 휴대폰에서 각각 한 번씩 넣으면 돼요.

### 기관 추가 요령
- **채용 게시판 '목록' 페이지 주소**를 넣으면 가장 잘 잡혀요. (예: `https://www.sac.or.kr/site/main/board/recruit/list`)
- 공공기관(잡알리오에 올라오는 곳)은 수집 방식을 **공공기관 채용정보 API**로 고르고, 기관 이름을 정식 명칭으로 적어 주세요.
- 다음 수집(다음 날 아침, 또는 '지금 수집 실행')부터 반영돼요. '기관 목록'에서 ✓ 몇 건인지, ⚠ 실패인지 확인할 수 있어요.

## 알아두면 좋은 점
- 자동 분류는 공고 제목의 단어로 판단해요("인턴", "기간제", "무기계약", "서포터즈" 등). 틀리면 사이트에서 바로 고치세요. 고친 분류는 계속 유지돼요.
- 마감일을 제목에서 찾지 못한 공고는 '마감일 미표기'로 보이고, 게시 후 30일이 지나면 마감 쪽으로 옮겨져요.
- 합격자 발표, 면접 안내, 입찰, 아카데미 수강생 모집 같은 글은 자동으로 걸러요.
- 기관 사이트가 개편되면 수집이 실패할 수 있어요. 상단에 ⚠ 경고가 뜨면 '기관 목록'에서 게시판 주소를 새로 바꿔 주세요.
- GitHub 예약 실행은 몇 분~수십 분 늦게 돌 수 있어요.

## 파일 구성
```
docs/                 사이트 (GitHub Pages)
  index.html, app.js, style.css
  data/companies.json 기관 목록 (사이트에서 추가/삭제 가능)
  data/overrides.json 직접 고친 분류/숨김
  data/jobs.json      수집된 공고 (자동 생성)
  data/status.json    기관별 수집 성공/실패 (자동 생성)
scraper/collect.py    수집 프로그램
.github/workflows/collect.yml  매일 자동 실행 설정
```
